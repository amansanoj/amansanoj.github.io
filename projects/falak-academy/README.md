# Falak Academy

A course platform built for teachers and students at my school to publish lessons, enroll in courses, and track completion. AbdulRahman Maniar and I built it around a single school community.

## Course Creation and Learning

Creators could organize a course into modules and lessons, then publish it for other members of the school. Students could self-enroll, work through the content at their own pace, and mark lessons complete.

Course creators could see enrollment and completion records. Those records made it possible to run a structured learning initiative rather than distributing a collection of unrelated links.

The application used Next.js and Supabase. The main product work was keeping the creation and enrollment flows understandable for people who weren’t administering an online-learning business.

## The Git and GitHub Pilot

The first course introduced Git and GitHub to students who were new to version control. It recorded **more than 60 completions**.

That pilot exercised both sides of the platform: publishing a structured course and following it through to completion. Its practical subject also gave students a concrete reason to use the platform.

## Project Period

We developed Falak Academy from June to August 2024. The original portfolio write-up records the course creation, enrollment, and pilot results.
